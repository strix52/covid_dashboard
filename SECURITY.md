# Security policy

This is a small, non-essential showcase project. The `main` branch is the only supported version.

Please report suspected vulnerabilities through GitHub's private vulnerability reporting flow when it is available for this repository. Do not open a public issue containing credentials, tokens, or an exploitable proof of concept.

The published dashboard has no third-party runtime packages. Dependabot monitors its pinned GitHub Actions dependencies, and the scheduled Archive integrity workflow checks the application syntax and committed data snapshot.
